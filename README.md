# Spam Email Detection

## 📌 Project Overview

Spam Email Detection is a Machine Learning project that classifies emails as **Spam** or **Ham (Not Spam)**.

The project uses Python and Machine Learning techniques to analyze email text and predict whether an email is spam.

## 🎯 Objective

The main objective of this project is to automatically identify unwanted or spam emails and separate them from legitimate emails.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Machine Learning

## 🔄 Project Workflow

1. Load the email dataset
2. Clean and preprocess the data
3. Convert text into numerical features
4. Train the Machine Learning model
5. Test the model
6. Predict whether an email is Spam or Ham

## 📂 Project File

* `spam.ipynb` — Jupyter Notebook containing the complete project code
